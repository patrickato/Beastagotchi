# Beastagotchi

Beastagotchi is an evolving local-first platform built around Pwnagotchi/Bettercap, a protected canonical Beast Core, live telemetry and history, a creature/lifecycle layer, touch-first presentation, Studio, Doctor/Procedures, content Packs and future extension/recovery tooling.

> **Development status:** v0.19 architecture foundation work is active on dedicated branches. Stable/release behavior remains separate from experimental migration work, and physical TFT acceptance remains its own gate.

The project intentionally evolves behind stable contracts rather than through a flag-day rewrite. Current architecture work preserves owner sovereignty, truthful unknown/stale/error state, read-broad/act-narrow authority, local/offline operation and rollback-first mutation.

For current implementation/migration status see `docs/architecture_migration_ledger.json` on the active architecture-foundation branch.

The existing project documentation, installation notes, roadmap, visual references and contributor information remain authoritative for the specific branch/release being used.
