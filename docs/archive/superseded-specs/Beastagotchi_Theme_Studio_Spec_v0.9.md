# Beastagotchi Theme Studio — v0.9

## Interaction model

The old six-button theme picker is replaced by a two-stage interaction designed for a 3.5-inch resistive touchscreen.

### Theme Library

- large full-width cards;
- three cards visible at once;
- vertical swipe to browse;
- the entire card is a touch target;
- active theme clearly marked;
- each card shows a small visual swatch, theme name, background type and motion profile.

### Theme Detail

Tapping a card opens a full-screen setup card. Changes preview live, but are not persisted until **APPLY**. **CANCEL** returns the previous theme/options.

The structure is intentionally extensible. Every theme can later register its own settings schema while still using the same Theme Studio.

## Matrix controls implemented in v0.9

- Layer: BACKGROUND or MIXED (some rain passes in front of content)
- Density: NORMAL / DENSE / STORM
- Speed: NORMAL / FAST / FURY
- Palette: GREEN / CYAN / VIOLET / RED / AMBER / RAINBOW / HOLIDAY

Runtime support also exists for custom primary/secondary/tertiary colors and accent mixing so a future web editor or on-device color picker can expose arbitrary palettes without rewriting the rain renderer.

## Matrix compositing rules

Background and foreground rain are separate compositor passes. A deterministic subset of streams becomes foreground rain in MIXED mode. Foreground streams are translucent to preserve readability.

The single CRT scanline is a protected final layer. It is not generated by the Matrix renderer and Matrix event reactions are not allowed to generate full-width horizontal pseudo-scanlines.

## v0.9.5 implementation update

The physical control model is now larger and paged rather than relying on precise taps. Touch targets use a shared measured hitbox policy independent of the visible row/button artwork.

### Matrix expanded schema

- Layer: Background / Mixed / Foreground
- Density: Sparse / Light / Normal / Dense / Heavy / Storm / Deluge
- Speed: Drift / Slow / Normal / Fast / Fury / Torrent
- Trail: Short / Normal / Long / Extreme
- Glyphs: Mixed / Digits / Binary / Hex / Symbols
- Palette: Green / Cyan / Violet / Red / Amber / Rainbow / Holiday / Custom
- Accents: Off / Sparse / Medium / Heavy / Balanced
- Foreground share: 0–50%
- Custom color slots: Primary / Secondary / Tertiary / Quaternary; slots 2–4 may be Off

A preset color plus `Accents=Off` is a strict single-color family. In Custom mode the active slots are independent; Beast does not silently inject a hidden accent color.

### Native Chroma

Native Chroma is a special Theme Studio target because its source is Jayofelony's real live frame rather than a Beast-created layout. v0.9.5 exposes:

- Ink source: Mood / Fixed
- Fixed palette: Green / Cyan / Amber / Violet / Red / White / Rainbow
- Glow: Off / Soft / Strong
- Effect: Clean / Scanlines / Vignette / Grain / Pulse / Glitch / Halo

Future versions can add element-aware treatment where the source mask and state registry permit it, but the original Pwnagotchi face/actions remain authoritative.
