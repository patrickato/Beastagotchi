# Beastagotchi Foundation Roadmap v2.7

v2.7 converts the post-v0.11 continuity work into a broader platform milestone. The detailed source of truth is `Beastagotchi_Master_Completion_Matrix_v4.2.md`.

## Validated foundation retained
- protected Pwnagotchi/Bettercap engine + read-only callback bridge;
- Beast Core canonical state/event/history/SQLite platform;
- reversible ILI9486 framebuffer ownership and calibrated ADS7846 touch;
- Native Pwnagotchi profiles, themes, Visualizer Studio, progression, Rare Moments and Expeditions;
- Resource Governor as a safety fallback.

## v0.13 integrated platform milestone

### Live-data integrity
- real Expedition route on Map;
- real per-channel history for Spectrum;
- explicit RSSI/channel semantics for Recon polar visualization;
- independent units/scales for System graphs;
- Telemetry Catalog source/freshness/quality metadata;
- user-configurable Live Dashboard with six canonical telemetry bindings.

### App-platform expansion
- ten main pages including Live Dashboard;
- App Registry independent of swipe-page count;
- category-filtered large app launcher;
- BeastDex persistent encounter browser;
- real Capture Vault file index;
- Telemetry Inspector and Performance attribution;
- Timeline, Notifications, Diagnostics, Services, Hardware and Storage app foundations.

### Beast Studio
- exact-compositor live preview using current Beast data;
- Theme/renderer/theme-option editing;
- Dashboard data binding and renderer editor;
- draft/undo/redo/reset/atomic Apply/backups;
- plugin integration catalog and transactional Plugin Manager control.

### Privileged action architecture
- public Beast Core HTTP remains read-only;
- local group-restricted Unix action socket;
- allow-listed typed actions only;
- plugin config/drop-in snapshot, CLI apply, verification, restart health observation and rollback;
- durable action audit/event history;
- protected Beast bridge and legacy-display conflict blocking.

### Efficiency / thermal direction
- batched local API requests;
- cached slow facts;
- dirty-row framebuffer writes;
- ambient-layer cadence independent of live data/touch cadence;
- static pages no longer redraw continuously at maximum permitted FPS;
- real process/render/framebuffer cost attribution.

## Next after v0.13 physical milestone

- Hardware Studio + accessory-role enrollment, then secondary Wi-Fi/Alfa and receive-focused SDR capabilities;
- richer Expedition archive/recap/notes/tags/replay and mapping layers;
