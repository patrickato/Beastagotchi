# Beastagotchi v0.11.0 Experience Gate

## Gate objective

Validate the first real Resource Governor, persistent Expedition foundation and three new structural themes on the physical Pi 4 + 480×320 ILI9486/ADS7846 target without destabilizing the known-good Pwnagotchi stack.

## Before physical ownership

The release must pass clean-package compile/import, shell syntax, all pytest tests, all-theme/all-page off-screen smoke rendering and the v0.11 validation-gallery generator.

## Physical checks

1. Home/System should show normal `FULL` or `GUARDED` behavior appropriate to the real temperature/load. Historical throttle flags alone must not hold `SURVIVAL`.
2. Observe temperature and governor mode while moving through visually busy themes/pages. Verify rendering remains responsive and the mode can recover after pressure subsides.
3. Change a visible Theme Studio option, induce/observe any governor reduction available during the session, then confirm the saved option returns unchanged when the governor recovers.
4. Inspect Synthwave, Amber Tactical and Ghost Minimal across Home, Spectrum, Expedition and System. Report illegible text, Moire/aliasing, touch-size problems or animations that look wrong on the TFT.
5. With GPS fix available, confirm Expedition route-point count/distance can grow. Confirm unique AP count and capture/XP deltas behave plausibly.
6. Restart Beast Core once during the physical gate and confirm the recent active Expedition is recovered rather than duplicated.
7. Quick Native RAW check: the actual Jayofelony frame/action/expression must still render.
8. Check footer arrows/Home and normal swipe/tap behavior on all newly touched pages.
9. Confirm Pwnagotchi and Bettercap remain healthy and the display release procedure returns physical ownership cleanly.

## Evidence to collect

Run `collect_display_validation.sh` before releasing display ownership. The v0.11 bundle includes health/state/events, recent Expedition APIs, framebuffer screenshot, UI runtime, touch gestures, journals and allowlisted hardware/status data.

## Pass criterion

No Pwnagotchi/Bettercap regression, no persistent false governor state, no Expedition corruption/duplication, no critical touch/navigation issue, and the three new themes are physically readable enough to continue refining rather than reverting.
