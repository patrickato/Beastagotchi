# Project Philosophy

Beastagotchi is being built for curiosity, learning, tinkering and community growth rather than a paid product tier.

The project should remain:

- free/open source;
- local-first where practical;
- transparent about what data is real versus unavailable;
- friendly to modification and extension;
- recoverable when experiments go wrong;
- respectful of the Pwnagotchi project underneath it;
- useful on the device itself without requiring a cloud account;
- capable of growing through optional modules rather than permanent base-image bloat.

Complexity is acceptable when it buys real capability, but complexity should be hidden behind coherent interfaces and good defaults. The final user experience should trend toward plug-and-play even when the underlying implementation is sophisticated.
