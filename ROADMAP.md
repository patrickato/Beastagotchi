# Beastagotchi Roadmap

This file is the public orientation layer. Detailed scope lives in the versioned roadmap, completion matrix and continuity ledger under `docs/`.

## Current baseline — v0.18.1

The platform/data/operations baseline is validated off-screen on the target Pi. Runtime code remains versioned 0.18.1 while repository documentation begins the v0.19 planning cycle.

## Next milestone — v0.19 Unified Experience Architecture

Primary goals:

- visual/interaction polish across the main page carousel and apps;
- stronger Beast/Home identity and progression presentation;
- consistent typography, hierarchy, icons, touch patterns and transitions;
- WebUI-first deep customization;
- Presentation Broker for Stock / Theme Manager / Beast UI ownership;
- responsive layout primitives for prudent additional display sizes;
- Beast Packs/Depot packaging foundations;
- Update Manager staging/verification/rollback foundations;
- phone/tablet companion/connectivity architecture;
- per-module performance/thermal attribution and efficiency work.

## Protected long-term scope

The following remain part of the project even when not in the current sprint:

- achievements, awards, secrets, codes/ciphers, rares and legendary events;
- Rare Cinematics and seasonal/celestial presentation;
- evolution, levels, growth, Beast personality and persistent progression;
- Expeditions, replay, Memory Vault/scrapbook and collections;
- Field Library, files, logs, backups, incidents and recovery tooling;
- Theme Studio, Visualizer Studio, Spatial Studio and user-created Boards;
- plugin/package management and downloadable content packs;
- multiple display classes and external Command Center surfaces;
- phone/tablet/web companion experiences;
- second Wi-Fi, Bluetooth, GPS, SDR, ADS-B, Meshtastic/LoRa and lawful sensor integrations;
- offline maps and a unified RF/field timeline/map;
- peer Beast/Monstergotchi concepts and accessory/sensor buses;
- dock/home-base modes, power hardware and learned runtime telemetry;
- optional local AI/voice under explicit privilege/resource policy;
- public installer/upgrader/migrations, CI, documentation and release engineering.
